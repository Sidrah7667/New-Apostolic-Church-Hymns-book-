# Christian Songs & Zaboor V2
Flutter Android app with Urdu/English labels.

Features:
- Add, edit, delete
- Search
- Favorites
- Categories
- Lyrics page
- Top-left video button opens the saved YouTube/video URL
- Local phone storage using SharedPreferences

Build:
flutter create .
flutter pub get
flutter build apk --release

APK:
build/app/outputs/flutter-apk/app-release.apk
